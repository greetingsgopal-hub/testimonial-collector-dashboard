## Problem Statement
Non-technical website owners (such as agencies, local services, and founders like Papa System) struggle to embed social proof on their live websites. The conventional "copy this raw `<script>` tag and paste it somewhere in your code" guide is confusing and leads to drop-offs. Customers don't know which page to open, where to find custom HTML/embed blocks in their page builders (Elementor, Shopify, Webflow, Framer, Wix), and cannot verify if the widget actually worked after publishing. Furthermore, incumbent social proof platforms (Senja, Testimonial.to) charge recurring monthly subscriptions to keep static widgets alive, creating hostage fee frustration.

## Demand Evidence
- Active real beta customer: Papa System (`papasystem.in`) is actively waiting to embed Panda Praise customer proof on their website to boost conversion rates and trust on paid traffic landing pages.
- Qualitative friction observed: When given a generic script tag, non-technical users hesitate to edit their live website builder without exact platform-specific instructions and live visual verification.

## Status Quo
- Currently, businesses manually take screenshots of WhatsApp messages or client DMs, crop them, and hardcode static images/quotes into page builders.
- This manual process takes hours, looks inconsistent, breaks responsiveness, and becomes a burden to update whenever new testimonials arrive.
- Existing SaaS tools (Senja, Testimonial.to) charge $29-$79/month to host and display testimonials, locking widgets if subscriptions lapse.

## Target User & Narrowest Wedge
- **Target User**: Founders and agency owners (e.g. leadership at Papa System) who run paid traffic or client pitches and need high-converting social proof near their primary CTA to stop lead bounce.
- **Narrowest Wedge**: A lightweight, fast-loading, zero-subscription widget embed with a 4-step guided installation workflow (Copy -> Open -> Paste -> Verify) and automated live-page verification for `papasystem.in`, backed by an instant no-code public hosted Wall of Love.

## Constraints
- The embed script must remain ultra-lightweight (<15KB) and load asynchronously so it does not hurt Core Web Vitals or mobile page speed.
- The widget installation UI must accommodate major website builders (WordPress/Elementor, Shopify, Webflow, Squarespace, Framer, Wix, and Custom HTML) without requiring custom server plugins.
- Must preserve strict tenant isolation in the backend worker API (`pandapraise.com/widget.js` and `/api/public/embed/testimonials`).

## Premises
1. **Non-Technical Installation Barrier**: Non-technical founders drop off because they do not know where to paste custom HTML blocks in their builder without breaking site layout.
2. **Dual-Door Share UX**: Offering both an instant direct public link (Hosted Wall of Love) and an embed code captures users who cannot immediately edit their website.
3. **Zero Monthly Hostage Fees**: Panda Praise wins against Senja by letting founders keep their social proof widgets active forever without monthly rent.

## Approaches Considered
### Approach A: Minimal Viable Embedded Script with Live URL Verification (Recommended)
- **Summary**: Refine the Senja-style modal and 4-step installation workflow in `WidgetStudio.tsx`; add automated live URL verification that crawls the customer page (e.g. `papasystem.in`) to verify the active script.
- **Effort**: S (human: ~1 day / CC: ~20 min)
- **Risk**: Low
- **Pros**: Builds directly on existing Cloudflare worker endpoints; provides instant feedback on customer site integration.
- **Cons**: Complex client-side SPAs might require manual preview confirmation.
- **Reuses**: `WidgetStudio.tsx`, Cloudflare `/widget.js` handler, `embedScript.ts`.

### Approach B: Universal Web Component & Ecosystem App Plugins
- **Summary**: Encapsulate the widget inside Shadow DOM Custom Elements and publish standalone WordPress and Shopify App Store plugins.
- **Effort**: L (human: ~2 weeks / CC: ~2 hours)
- **Risk**: Medium
- **Pros**: Complete CSS isolation and 1-click app installs.
- **Cons**: Heavy overhead maintaining multi-ecosystem plugins; delays launch for immediate users like Papa System.

### Approach C: Zero-Code Tag Manager & Floating Proof Hub
- **Summary**: Deliver widgets primarily via Google Tag Manager (GTM) containers and floating popup toasts with custom subdomain mapping.
- **Effort**: M (human: ~4 days / CC: ~45 min)
- **Risk**: Low
- **Pros**: No layout editing needed in page builders.
- **Cons**: Requires customers to have GTM configured.

## Recommended Approach
**Approach A: Minimal Viable Embedded Script with Live URL Verification.**
It solves Papa System's immediate need to embed testimonials on `papasystem.in` without friction or delay, leverages our existing Senja-style share modal architecture, and eliminates non-technical installation fear via automatic live verification.
