## Edge Cases
- Website URL entered without `https://` — automatically normalizes to `https://`
- Malicious redirect chain to `169.254.169.254` (cloud IMDS) or `127.0.0.1` — blocks with HTTP 403 `FORBIDDEN_HOST`
- Slow or hanging target website — triggers 5-second `AbortController` timeout and returns `TIMEOUT` without crashing worker
- Oversized target HTML (>10MB) — streams and stops reading at 512KB cap to prevent worker memory exhaustion
- Script tag pasted without `#panda-praise-wall` container div — returns `SCRIPT_FOUND_CONTAINER_MISSING` (`verified: true`) because `embedScript.ts` auto-mounts dynamically
